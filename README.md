# Workout Studio

Минималистичное Android-приложение для тренировок: таблица упражнений + умный таймер
отдыха между подходами, который сам сигналит звуком и вибрацией, чтобы не пересиживать.

## Возможности

- **Упражнения** — таблица с названием, временем отдыха, числом повторений и подходов.
  Список сохраняется на телефоне.
- **Таймер отдыха** — большой обратный отсчёт, отметки подходов (1/3 → 2/3 → 3/3),
  кнопки **+15 сек**, **пропустить**, **отмена**.
- **Сигнал в конце** — звук + вибрация, плюс уведомление при работе в фоне.
- **Настройки** (4 тумблера): вибрация, звук, работа в фоне, не гасить экран.
- Чёрно-белая тема, светлая и тёмная (следует системной).

## Как собрать APK (всё в облаке, ничего ставить не нужно)

Сборка идёт на серверах GitHub через **GitHub Actions**. Твой компьютер не используется —
Android SDK и всё остальное живёт в облаке.

### Шаг 1. Запушить код
В **GitHub Desktop**:
1. Слева внизу впиши Summary (например, `first version`).
2. Нажми **Commit to main**.
3. Нажми **Push origin** (вверху справа).

### Шаг 2. Дождаться сборки
1. Открой репозиторий на сайте **github.com**.
2. Вкладка **Actions** → увидишь запуск **Build APK** (жёлтый кружок = идёт, ~3–5 мин).
3. Зелёная галочка = готово.

> Если у тебя ветка называется `master`, а не `main` — это ок, workflow ловит обе.
> Запустить сборку вручную можно там же: **Actions → Build APK → Run workflow**.

### Шаг 3. Скачать APK
1. Кликни на завершённый запуск (с зелёной галочкой).
2. Внизу страницы блок **Artifacts** → **workout-studio-debug-apk**.
3. Скачается zip — внутри файл **app-debug.apk**. Распакуй.

### Шаг 4. Установить на телефон
1. Перекинь `app-debug.apk` на телефон (кабель, Telegram «себе», Google Drive — как удобно).
2. Открой файл на телефоне.
3. Android попросит разрешить **«Установка из неизвестных источников»** для проводника/браузера —
   разреши и вернись к установке.
4. Готово, иконка появится в списке приложений.

> Это **debug**-сборка, подписанная отладочным ключом — для личной установки этого достаточно.
> В Google Play такую не публикуют, но на свой телефон ставится без проблем.
